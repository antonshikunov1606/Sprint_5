# Описание проекта

Этот проект представляет собой набор автоматизированных тестов для веб-приложения

## Структура проекта

- **conftest.py**: В этом файле содержатся фикстуры

- **locators.py**: Этот список включает в себя набор локаторов, которые используются в тестах для поиска и взаимодействия с элементами пользовательского интерфейса

- **test_registration_page.py**: Тесты для проверки функциональности страницы регистрации
- 
- **test_login_page.py**: Тесты для проверки возможностей страницы авторизации

- **test_logout.py**: Тесты сценариев выхода из аккаунта (разлогина), проверяющие корректность процесса завершения сеанса пользователя
- 
- **test_navigation_panel.py**: Содержит тесты, которые проверяют функциональность навигационной панели, обеспечивая правильность переходов и доступность всех разделов

- **test_constructor_page.py**: Тесты для проверки работы компонента "Конструктор"
